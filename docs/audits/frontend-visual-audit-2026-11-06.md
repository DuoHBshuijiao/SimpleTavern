## 第 1 批：作者裁定（2026-11-06）

- **气泡不模糊是有意设计，不是问题。** 背景图是用户审美的一部分，模糊气泡会到处遮挡图片；文字可读性由用户自己负责（RikkaHub 的助手无气泡，也就无模糊）。可接受的变化：只让用户气泡模糊，助手气泡保持不模糊。不要再提“阅读幕布”这类遮挡图片的方案。
- **危险操作：** 现在确实太亮，但不应完全去掉醒目作用。降低亮度，保留醒目。
- **设置页是要解决的问题：** 信息层级混乱；解释性小字太多且不统一；有些设置项有自己的背景边框，有些没有，需要统一。

本节其余观察作者尚未表态，不要默认已通过。

已落实（未提交）：用户气泡加 6px 模糊、危险按钮去光晕改淡底红字、设置页按 `styles/components/settings.css` 顶部注释的四级结构统一（面板是唯一带边框的一层；公共组件 `SettingsField`、`SettingsSwitch`、`SettingsHint`）。原有说明文字收进 ⓘ，没有删除。

作者后续选择（2026-11-06）：

- 这次做：文字层级、旁白正体加颜色、滚动边缘淡出、助手面板让位、生成结束与按钮动效。
- 沉浸动画：保留收起侧栏后的停顿，它有加载、蓄力确认的手感，时长约一秒，只微调不缩短到一两百毫秒。
- 等待首包：头像放大缩小的呼吸很难看，不要用。光弧也不合适，因为给软件引入了光源。改为头像外圈转一段中性弧线，头像本身不动。
- 切换会话过渡：涉及整个聊天区的整体滚动，太激进，不做。
- 侧栏减框、背景亮度处理、角色氛围色：这次不做。
- 滚动边缘淡出的遮罩会隔断气泡的 `backdrop-filter`（已实测），两者只能留一个。作者选择保留淡出，用户气泡不模糊。

- 发光效果（结束光圈、按钮彩色阴影）：作者认为玻璃界面引入光源是危险的设计，但现有效果先保留，看不顺眼再去掉。不要再新增发光效果。

## 第 1 批：当时的观察（讨论材料）

以下是作者裁定前写的，与上面的裁定冲突时以裁定为准：

- `--color-text-secondary` 和 `--color-text-muted` 取值相同，层级没有区分。
- 斜体旁白用这个颜色，对比度：无背景 6.9，深色 30% 约 6.8，深色 50% 5.8，浅色 30% 3.3。
- 中文旁白靠合成斜体区分。
- 气泡没有模糊：用户气泡 15% 主题色，助手气泡 0.9 不透明。深色 50% 时图标透到文字后，用户气泡局部最低约 2:1。
- 名字、提示语、操作行直接压在图上：深色 50% 名字约 2.7:1，浅色 30% 提示语约 3.6:1。
- 各层材质与 `DESIGN.md` 的 L0–L6 对不上：侧栏 0.86 + 模糊 6px，输入框 0.81 + 模糊 12px，气泡无模糊。
- 背景透明度只是和深色底混合，亮图 30% 时发灰。
- 侧栏三层边框；简介被切掉半行；“暂无简介”的卡片也占同样高度。
- 消息从顶栏上方 12px 的缝里露出，在输入框上沿被硬切。
- 助手面板盖住输入区。
- API 预设在 500px 抽屉里挤成两栏。
- “删除”悬停时带红色光晕，是操作行里最醒目的按钮。
- 进入长开场白时停在结尾；头像 40px，角色存在感弱。

当时提出的方向：阅读幕布、背景亮度与饱和度处理、文字层级与阅读字体、统一材质、滚动边缘遮罩、角色氛围色。

## 现有沉浸动画

顺序：侧栏让位，等待 1000ms，顶栏上升贴顶（420ms），横向展开（520ms），输入框下沉、提示语淡出，Agent 控件滑入。

待改进（未决定）：

- 1000ms 空档容易被当成卡顿，建议 200–300ms。
- 恢复时 180ms 同时完成，和进入不对称。
- 沉浸状态只传给着色器，图片背景和消息列没有反应。
- 入口只有一个小箭头。
- 缓动曲线不统一。

## 愉悦交互候选（第 2、3 批，未决定）

原则：先让位、再到位，一次一个主角；只动 `transform` 和 `opacity`；遵守“减少动态效果”设置。

- 发送：文字从输入框飞入气泡。
- 等待首包：头像外圈呼吸（第 0 批去掉占位后，这段时间只显示头像和名字）。
- 思考中：实时计时，结束时收拢成小卡片。
- 生成结束：输入框边缘走一次淡光，“停止”平滑变回“发送”。
- 切换会话或角色：View Transitions 淡入淡出，头像从侧栏过渡到消息列。实测当前内容瞬间替换。
- 弹窗：统一入场和退场。实测身份编辑无动画，导入和建群有。
- 调背景透明度：拖动时遮罩淡出、抽屉变透明。
- 切换主题：从点击位置圆形扩散。
- 搜索跳转：目标消息闪一次高亮环。
- 删除：平时不发光，点击后原地变“确认？”，删除时高度收拢并可撤销。
- 重写或切换版本：左右滑动（现状未实测）。
- 回到底部：生成中显示新内容提示。
- 图片背景：鼠标视差 ±6px，默认关闭。
