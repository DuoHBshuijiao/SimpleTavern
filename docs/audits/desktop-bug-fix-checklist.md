# SimpleTavern Desktop 待修复清单

清单按所需的验收证据分组，每组沿用原审计顺序。「序号」是修复清单编号，「原审计号」用于定位原条目。原审计 119 项中有 118 项列入清单，其中 2 项待产品裁定。见[完整审计记录](code-audit-2026-11-11.md)。

## 1–117 本地测试、编译测试与 CDP

通过本地单元或接口测试、编译构建、隔离浏览器的 CDP 检查复验。布局和交互以元素位置、命中检测、焦点及实际点击为依据。相关构建通过后可复用现有检查入口。[API 检查](../../tools/api-check/run.py) · [CDP 界面检查](../../tools/ui-check/run.py)

供应商请求和响应使用本地替身，真实供应商验证延期。JanitorAI 使用已有脱敏结构和本地隔离实例，现有最长样本作为覆盖证据。WebGPU 使用设备生命周期、提交帧计数和有限运行窗口。
