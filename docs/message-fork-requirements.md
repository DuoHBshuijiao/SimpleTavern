# SimpleTavern 消息回溯分叉功能需求

> 2026-05-20 整理，按老爷意见修订：硬分叉到新会话，不纠缠单文件内的 forkId 分支链。

## 一、定位

任何一条消息气泡下方菜单内按钮 → "从此处分叉到新会话"。新会话复制该消息之前的所有对话历史，用户在新会话中写替代回复，两条时间线各自独立发展。前端组件不要添加文本title，但需要aria label

**不是 AI 给选项。** 主动分叉，硬分叉——新会话就是新文件，干净利落。

## 二、交互流程

```
源会话                                新会话
──────                                ──────
msg_001                               msg_001  ← 复制
msg_002  ← 用户"分支"                 msg_002  ← 复制
msg_003                               [用户输入新回复]
msg_004                               msg_003F  ← 分叉点
                                      msg_004F  ← 正常续写
```

1. 用户在源会话的某条消息（msg_002）上点击"从此处分叉到新会话"
2. 系统创建新会话，复制 msg_001 到 msg_002 的全部内容
3. 新会话自动打开，输入框获得焦点，用户写替代回复
4. 源会话不受影响，继续按原时间线发展
5. 两个会话完全独立——各自的历史、各自的 MVU 状态、各自的知识图谱

## 三、API

### 3.1 创建分叉会话

```
POST /api/chats/{source_chat_id}/fork
```

请求体：
```json
{
  "forkAtMessageId": "msg_002",
  "newChatName": "分叉：源会话名（可选，不填则自动生成）"
}
```

后端逻辑：
1. 加载源会话的全部消息
2. 找到 `forkAtMessageId`，截取该消息及其之前的所有消息
3. 创建新 Chat 对象（新 `chat_id`，新文件名）
4. 复制截取的消息到新会话（深拷贝，不共享引用）
5. 新会话的 `characterId` 同源会话（单聊），或 `memberIds` 同源会话（群聊）
6. 不复制源会话的 `stateVariables`（状态栏从零开始）
7. 返回新会话的 `chat_id`

### 3.2 获取会话祖源

```
GET /api/chats/{chat_id}/fork-lineage
```

返回分叉链：该会话是从哪个会话的哪条消息分叉出来的，以及它的"兄弟"分叉会话列表。用于在前端显示"此会话分叉自 XXX"。

## 四、前端交互

### 4.1 右键菜单

- 悬停消息 → 消息气泡右上角出现 `···`
- 菜单项："从此处分叉到新会话"
- 点击后弹出轻量确认框（可选填写新会话名称）
- 确认 → API 调用 → 新标签页打开新会话（或侧栏切换）

### 4.2 分叉溯源

- 在新会话顶部显示："分叉自「源会话名」的第 N 条消息"（可点击跳转源会话）
- 源会话的分叉点消息旁显示："已有 X 个分叉"（可点击查看分叉会话列表）

### 4.3 视觉标记

- 分叉会话在会话列表中以缩进或图标标记区分
- 不需要 `┣━` 分支线——新会话就是新文件，标记太复杂反而喧宾夺主

## 五、边界条件

- **不限制分叉次数**：可以从同一消息多次分叉，生成多个平行新会话
- **分叉的再分叉**：新会话也可以再次分叉（与普通会话无异）
- **角色 greeting**：新会话复制历史消息后，不自动生成 greeting。用户输入第一条 fork 回复后正常触发 assistant 响应
- **群聊**：分叉群聊会话时，`memberIds` 一并复制。新群聊会话从零开始维护自己的 MVU 状态
- **聊天助手**：新会话自动继承源会话的助手设置

## 六、与现有系统的对接

- **导出**：每个分支独立导出，互不干扰
- **`/forget`**：仅作用于当前会话
- **删除会话**：删除源会话不影响分叉子会话（消息已深拷贝）
- **存储**：新会话 = `data/chats/{new_chat_id}/` 下的独立目录，与现有会话完全一致

## 七、实现顺序

1. `POST /api/chats/{chat_id}/fork` 端点（截取消息 + 创建新 Chat）
2. `GET /api/chats/{chat_id}/fork-lineage` 端点
3. 前端：右键菜单
4. 前端：新会话跳转 + 分叉溯源显示
