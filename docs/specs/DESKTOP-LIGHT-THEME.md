# 桌面亮色主题设计规范

亮色主题用中性色面、留白和字重建立阅读顺序，用主题色标识主要操作和当前位置。聊天内容在壁纸上保持清晰，密集设置可以顺着标题和字段快速扫读。全界面采用无描边样式。

本规范适用于桌面版在浏览器中打开的 Vue 前端。固定亮色、跟随系统和跟随背景只要解析为亮色，都使用同一套规则。七个色系共享中性表面、文字层级、组件形态和交互状态。本文定义改造目标，配色表给出可直接用于样板的色值。

## 1. 无描边规则

- 外框、卡片边线、页头页脚分隔线、选中环、内描边和拖放虚线统一改用色面、留白或状态标记。外部阴影只用于浮层和贴在壁纸上的主要悬浮区域，使用柔和扩散阴影。
- 面板靠整块色面建立边界，面板内分组靠标题、对齐和间距。普通列表用行距分组，交互行通过填色反馈。
- 控件在静止时就要能被识别。下拉用箭头，复选用形态和勾选，可编辑区域用可见标签和清晰色面。空白输入区若只能通过填充识别，填充与相邻色需达到必要的非文字对比度。
- 图标笔画、链接下划线、滑块轨道、图表标记和内容语义按各自用途绘制。系统强制颜色模式使用平台提供的控制边界和焦点表达。 [W3C 非文字对比度](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)

## 2. 中性色和视觉层级

沿用现有 L0–L6 的层级语义。层级表示表面用途和叠放关系。相邻区域可通过空隙和填充共同区分，浅色表面之间无需逐层增加亮度。

| 层级 | 使用位置 | 样板表面 | 阴影 |
| --- | --- | --- | --- |
| L0 页面 | 应用画布、无壁纸背景 | #F3F5F5 | 无 |
| L1 导航 | 侧栏外层、固定的导航区 | #EEF2F2，壁纸上约 96% 不透明 | 无 |
| L2 聊天顶栏 | 会话标题和同层工具区 | #F4F7F7，壁纸上约 96% 不透明 | 无 |
| L3 容纳内容的面板 | 侧栏内容区、嵌入面板、聊天工具的局部面板 | #F8FAFA，壁纸上约 98% 不透明 | 无 |
| L4 悬浮工作区 | 主输入区、设置抽屉外层 | #F8FAFA，壁纸上约 98% 不透明 | 0 8px 24px，#192D31 约 12% |
| L5 对话框 | 角色编辑、表单弹窗、重要确认 | #FFFFFF，实色 | 0 16px 48px，#192D31 约 16% |
| L6 局部浮层 | 下拉、菜单、工具提示、就近确认 | #FFFFFF，实色 | 0 12px 32px，#192D31 约 18% |

设置抽屉的内容面用近白，字段用较深的中性填充。标题区、标签页和底部操作区通过间距、对齐与选中填色定位。参考遮罩为深中性色，设置抽屉约 16%，需专注的模态弹窗约 28%。同一模态层使用一次遮罩。

角色消息底色用 #FFFFFF，用户消息用较淡的主题色面。方向、署名和位置继续表达发言者。壁纸区域使用单层材质，聊天滚动区内的消息用稳定的填充。引用、代码块和表格通过独立底色、对齐及留白表达内容结构。头像字、正文、控件和浮层的对比按真实合成背景验收。 [Fluent 2 层级](https://fluent2.microsoft.design/elevation) · [Material 3 色彩角色](https://m3.material.io/styles/color/the-color-system)

| 颜色角色 | 浅色样板 | 用法 |
| --- | --- | --- |
| 正文 | #20292B | 标题、正文、控件当前值 |
| 次要文字 | #4D5A5D | 次级标签、角色描述、辅助操作 |
| 低强调文字 | #536063 | 时间、字号单位、占位提示。仍按实际表面测量 |
| 控件填充 | #E9EEEE | 输入、下拉、次按钮底色 |
| 控件悬停 | #DCE5E6 | 中性控件和可操作列表行 |
| 控件按下 | #CFDADD | 中性控件的短暂按下反馈 |
| 控件标记 | #68777A | 滑块轨道、关闭态开关、滚动条等需要清晰辨认的部位 |
| 语义反馈 | 信息 #234E91 / #E4EDF7，成功 #204C3A / #E2EFE7，警告 #653B13 / #F7ECD9，错误 #862438 / #F8E5E8 | 每组为文字或图标色 / 底色，配合文字或图标表达语义 |

## 3. 主题色分配

- **高强调**给当前操作区的主要动作。聊天的「发送」和设置的「保存设置」使用深主题色填充与白色前景。每个操作组用一个最高强调动作。
- **中强调**给当前位置和已经选择的项目。当前标签、角色、选项使用浅主题色底与深主题色前景。需要确认选择时加勾选或选中标记。
- **低强调**给用户消息等大面积主题提示。可用 6%–8% 主色与实色白混合，保持与选中底色的强度差。正文链接沿用深主题色和下划线。
- 主题色通过共用的颜色变量进入组件。语义反馈、头像识别色、中性表面和静止态普通控件使用各自的颜色角色。 [Fluent 2 色彩](https://fluent2.microsoft.design/color) · [W3C 色彩使用](https://www.w3.org/WAI/WCAG22/Understanding/use-of-color.html)

七个主色沿用当前亮色值。浅选中底色以 14% 主色与白色混合并取整得到。主按钮悬停、按下可分别以 12%、24% 的深中性色 #20292B 调暗主色作为样板，生产验收覆盖两种状态的文字对比。

| 鼠尾草 | #2B5846 | #E1E8E5 | 8.12:1 | 6.52:1 |
| 青碧色 | #205A65 | #E0E8E9 | 7.74:1 | 6.23:1 |
| 雾紫色 | #4C448C | #E6E5EF | 8.36:1 | 6.69:1 |

## 4. 字体、间距和形状

- 沿用界面字体、独立阅读字体和用户的字号、行高设置。以默认字号为基准，面板标题参考 18px / 600，分组标题参考 14px / 600，常规界面文字参考 14px / 400，辅助文字参考 12px。必要的提示和可操作标签使用常规界面字号或满足可读性的现有紧凑变体。
- 使用现有间距尺度。标签和字段参考 4–8px，同组字段参考 12–16px，独立分组参考 24px，主要容器内边距参考 16–24px。窄窗口中优先换行和重排，同组关联保持清晰。
- 普通控件使用现有 0.75rem 圆角和 2.25rem 常规高度，面板与浮层使用 1–1.5rem 圆角。头像和标签沿用各自组件的形状。键盘焦点、加载和选中状态保持原有点击区与布局尺寸。
- 悬停、展开和反馈动效沿用共用时长，常见反馈约 150–200ms。尊重减少动态效果设置。焦点和关键状态在静止时也能识别。

## 5. 组件与状态

| 组件 | 默认样式 | 状态样式 |
| --- | --- | --- |
| 按钮和图标动作 | 主按钮为实心主题色，次按钮为中性填充，工具栏低强调动作保留可辨图标与命名 | 悬停、按下用填色变化。危险操作用语义色与动作名称。加载有明确状态并维持按钮位置 |
| 输入和数字步进器 | 持久标签配合连续色面。步进器内用间距和图标组织按钮与数值 | 错误使用有色底、错误提示及字段关联。只读和禁用按语义呈现，可读取的值保持辨认 |
| 下拉、组合框和模型选择 | 触发器用控件填充和箭头。浮层用实色表面，搜索区与选项靠间距分组 | 展开用箭头与触发器填色，已选用底色和勾选。方向键移动时，焦点轮廓移到实际指向的候选项 |
| 开关、复选和滑块 | 开关用滑块位置，复选用勾选形态，滑块用可辨的实色轨道与滑块 | 开关开与关分别使用主题色与中性色，范围滑块以滑块位置和数值表达状态 |
| 标签页、列表和标签 | 标签页和列表用对齐与行距，弱交互标签用低强调填充 | 当前项用浅色填充与位置、文字强调或勾选。悬停、当前项和焦点并存时仍可区分 |
| 抽屉、编辑器和专用面板 | 使用对应的表面层级。助手、MVU、日志、世界书、代码块和附件共享中性底色与分组规则 | 用局部填色区分状态和子区域。上传拖放时高亮整块区域，裁剪通过遮罩和手柄表达边界 |
| 通知、确认和错误 | 用较实底色、标题和操作形成层级 | 状态色配文字。删除等操作沿用现有确认流程，颜色与文案共同表达后果 |

**键盘焦点**在深浅色中共用单层 2 CSS px 轮廓。同一控件的轮廓位置和形状由组件确定，颜色跟随主题，强制颜色模式使用系统高亮。文本输入区只在文字控件上显示一层焦点轮廓。下拉中的勾选表示已选项，轮廓指示方向键当前指向的候选项。保留顶层弹层接管焦点、逐层关闭和关闭后回焦。 [W3C 可见焦点](https://www.w3.org/WAI/WCAG22/Understanding/focus-visible.html)

亮色文字选区用深主题色作为高亮底色，选中文字用白色。输入框和普通正文共用这套选区配色。

## 6. 占位头像

- 头像字和底色为一对实色，文字绘制在最上方。保留名称到配色的稳定映射，聊天气泡、角色侧栏、用户身份、群成员、会话缩略图和角色编辑共用组件。
- 清理名称前导空白后取第一个可见 Unicode 字素。拉丁首字母可转大写，转换扩展成多个字符时保留原字符。没有可见字符时显示问号。
- 无图片、图片加载中和加载失败时显示可读的占位。图片加载成功后替换占位，换源时重置状态，并忽略旧源迟到的结果。图片预览入口以当前图成功加载为条件。
- 头像组件拥有用于占位的底色和文字色。调用处按布局传入尺寸、圆角和裁切位置。实图和占位均遵循亮色无描边规则。

## 7. 改造顺序

| 批次 | 主要入口 | 交付结果 |
| --- | --- | --- |
| 1. 主题基础与共享控件 | 根主题变量、表单与按钮 CSS、浮层表面、滚动条、ModernAvatar、ModernSelect | 亮色表面与状态来自共用角色。头像可读。展开态轮廓、伪元素与内描边一并清理。滚动条改用自己的填色变量 |
| 2. 青碧色审阅样板 | 聊天、侧栏、主输入框、设置抽屉、下拉和角色编辑 | 同分辨率、同壁纸、同位置对照。聊天弱化外壳，设置可按标题扫读，保存按钮最显眼，浮层和焦点可辨 |
| 3. 扩展到全部组件入口 | 当前会话与 API 预设、群聊、助手、TTS、MVU、世界书、日志、导入导出、通知与确认 | 所有同类组件使用相同状态表达。清理页面级 Tailwind 描边、硬编码边色、伪元素描边和仿描边的阴影 |
| 4. 回归验收 | 构建产物和 Windows 发布包打开的浏览器 | 全部亮色色系、壁纸条件、键盘与主题切换通过验收，暗色用作回归对照 |

实现时从根节点的亮色属性应用主题，使挂载到 body 的浮层获取同一套样式。优先复用现有 L0–L6、主动作、表面、滚动条、文字和语义变量。共享组件缺少可复用角色时在共用样式定义，页面通过组件变体或语义变量应用。

## 8. 验收标准

| 验收项 | 通过条件 |
| --- | --- |
| 无描边 | 检查默认、悬停、按下、展开、选中、禁用、加载、错误和拖放状态。截图和计算样式中，面板、控件、分组和头像的装饰性外框、分隔线、内描边、状态环均消失 |
| 可读性 | 默认字号下普通文字、必要占位提示和头像字至少 4.5:1。识别控件或状态所需的非文字视觉信息与相邻色至少 3:1。透明表面以合成后颜色计算 |
| 键盘 | Tab 和 Shift+Tab 可追踪焦点。方向键移动存在的活动项，Enter 提交选项，Esc 逐层关闭并回焦。焦点、悬停、当前导航项与已选项能分辨 |
| 头像 | 用中文名、拉丁名、空白名与多码点字符检查常见尺寸。覆盖无图、坏图、换上新图及旧图迟到返回 |
| 外观和尺寸 | 七个亮色色系检查关键组件和状态。以无壁纸、浅色壁纸、深色或高纹理壁纸的约 30% 透明度检查。代表性样板覆盖 1440px、1100px、420px 视口，并复核常用桌面缩放 |
| 切换与浮层 | 固定、系统和背景跟随模式切换后，抽屉、弹窗、下拉、原生控件与页面同步。设置草稿可预览，取消和保存分别恢复或持久化对应外观 |

复用外观回归入口，将选择器描边一致性的旧断言改为无描边、可识别、键盘状态有效的检查。以生产构建为截图与样式基准，并保留青碧色样板的成套截图供后续组件评审。 [外观回归入口](../../tools/ui-check/appearance_checks.py) · [W3C 文字对比度](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html) · [W3C 非文字对比度](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)
