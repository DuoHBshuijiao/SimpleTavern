# SimpleTavern 移动交互 Demo

这是 2026-09-29 讨论的手机交互框架原型：进入故事、用输入区的「＋」组合人物与情境、查看故事记忆、在历史中按人物和故事找回会话。桌面会显示一个手机画布与快捷入口，窄屏则铺满视口。

可以直接打开 `index.html`，也可以用任意静态服务器提供这个目录。文件没有外部资源或依赖；所有人物、故事、连接与回复都是演示数据，不调用模型 API，不访问现有应用数据。

可操作的主要路径：

- 发送示例消息，停止示例回复，编辑回复和切换版本。
- 从「＋」调整人物、我方身份、场景与目标；继续原故事或独立开场。
- 新会话延续当前故事记忆；独立故事使用空白记忆。
- 历史中搜索、按人物与故事筛选、切换会话。
- 编辑故事记忆，查看人物原稿和单独准备的身份版本。
- 创建人物，预览首次使用的连接 → 模型 → 人物路径。
- 查看应用设置的分组与返回关系，切换默认或会话模型、预览字号、导出虚构数据。

浏览器以 `simpletavern-mobile-story-demo-v1` 单独保存演示修改。工具、技能、工作区和生成任务页用于展示下一层入口，不执行这些能力。原生 Android 返回键、软键盘、后台恢复与真实业务都不属于本轮验证。

这个原型没有定稿作用。尤其人物配置与会话覆盖的最终归属、故事的数据结构、记忆迁移及局域网能力，还需在正式实现前另行确定。
